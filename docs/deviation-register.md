# Deviation register

Every deliberate departure from a 1:1 transliteration of the C core, in one place. Location and format are fixed by the crate and API architecture decision ([ADR 0004](adr/0004-crate-api-architecture.md), wayfinder ticket #10); the port strategy ([ADR 0001](adr/0001-port-strategy.md), ticket #6) makes the register part of the spec: side-by-side debugging against the C oracle is only possible if every deviation is known.

Format (stable): one row per deviation, columns are ID, C site, deviation (what Rust does instead), why, decided in, and gate (what keeps the deviation honest). IDs are stable and never renumbered; superseded entries keep their ID with a "superseded by" note; new entries are appended with the next free ID.
